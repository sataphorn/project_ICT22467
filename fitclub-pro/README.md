> เดโมรันฐานข้อมูล **SQLite ในเบราว์เซอร์** (WebAssembly) โดยโครงสร้างตารางและตรรกะเหมือนเวอร์ชัน MySQL
> ข้อมูลอยู่ในเบราว์เซอร์ของผู้ชมแต่ละคน **รีเฟรชหน้า = รีเซ็ตเป็นข้อมูลตัวอย่าง**

### ลองอะไรได้บ้าง
- **สมาชิก:** สมัครสมาชิก → ดูตารางคลาสรายสัปดาห์ → จอง/ยกเลิก → โปรไฟล์ (แพ็กเกจ, ประวัติเช็คอิน, เปลี่ยนรหัสผ่าน)
- **เช็คอินหน้าประตู:** ใส่รหัสสมาชิก เช่น `M00001` (สำเร็จ) / `M00003` (แพ็กเกจหมดอายุ → เข้าไม่ได้)
- **เทรนเนอร์:** รายงานคลาส รายชื่อผู้จอง เช็คชื่อ มา/ไม่มา (เช็คได้เฉพาะคลาสที่เริ่มแล้ว)
- **ผู้ดูแล:** แดชบอร์ด · จัดการข้อมูลครบ 8 ตาราง (เพิ่ม/แก้ไข/ลบ)
- ปุ่ม **"โหมดคอลัมน์ DB"** มุมขวาบน แสดงชื่อคอลัมน์ในฐานข้อมูลข้างทุก Field

## 📁 โครงสร้างโปรเจกต์

```
docs/        เวอร์ชันเดโมสำหรับ GitHub Pages (SQLite ในเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์)
public/      หน้าเว็บของเวอร์ชันเต็ม (เรียก API ไปที่ server.js)
server.js    เวอร์ชันเต็ม: Node + Express + MySQL
db/          schema.sql (MySQL 8) และ seed.js (ข้อมูลตัวอย่าง)
```

## ▶ รันเวอร์ชันเต็ม (Node + MySQL) ในเครื่องตัวเอง

ต้องมี Node.js 18+ และ MySQL 8.0.16+

```bash
npm install
# ถ้า MySQL มีรหัสผ่าน (Windows: set DB_PASSWORD=... / Mac,Linux: export DB_PASSWORD=...)
npm run seed     # สร้างฐานข้อมูล fitclub_pro + ข้อมูลตัวอย่าง
npm start        # เปิด http://localhost:3000
```

เมื่อเปิดเซิร์ฟเวอร์ ใน terminal จะบอกว่าเชื่อมต่อฐานข้อมูลสำเร็จหรือไม่ พร้อมเหตุผลถ้าไม่สำเร็จ

## ⚙ เปิดเดโมบน GitHub Pages

1. อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub repo
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` · Folder: **/docs** → Save
3. รอ 1–2 นาที ลิงก์จะขึ้นที่หน้า Pages
